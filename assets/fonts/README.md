# Fonts

Plus Jakarta Sans, a variable font (weights 200 to 800), served from this repo instead of Google Fonts so pages load faster and make no third-party requests for text.

- `plus-jakarta-sans-latin.woff2`: Latin characters
- `plus-jakarta-sans-latin-ext.woff2`: Latin extended characters (loaded only if a page uses them)
