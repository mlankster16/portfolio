Interactivity Generator

Helping our team create small, useful learning interactions.

I designed and built a tool for Duke’s learning design team to turn course content into interactive activities.

It has two connected parts: a generator that helps designers create and edit an activity, and a plugin that places the finished activity in Coursera.

Where we started

Sometimes a single concept benefits from a small interaction: a quick question, a sequence to arrange, or a visual learners can explore.

I wanted our team to have an easier way to create those moments in Coursera. The aim was to help designers work from their content and learning goal, try a suitable format, and prepare the activity for the course.

Building the two parts

I first built a plugin that embeds finished HTML and JavaScript in the Coursera course environment.

Then I built the generator to support the work that comes before that. A designer describes what they want learners to understand or practice, and the tool helps them explore possible interaction formats.

Designers can also choose a format directly when they already have something in mind.

Keeping the learning goal in view

The generator uses Claude and a set of learning design guidelines to suggest formats such as a short quiz, a tabbed explorer, or a sequencing activity.

It also offers guidance when a request needs more detail, contains too much for one activity, or may work better in another format.

I wanted the recommendations to help designers think through their options and make an informed choice.

Giving designers room to review and edit

Once an activity is generated, the designer gets a working preview. They can explore alternatives and edit the visible text without changing the code.

Subject-matter experts can review the content with the designer before it goes into a course.

When the designer is ready, the tool exports the configuration needed to embed the activity, along with a static text version of the content.

See the workflow in practice

The working tool uses Claude to respond to the content a designer brings to it.

The walkthrough below uses one fixed example so you can explore the same process without an API key: describe a learning need, consider a format, review and edit the activity, and export the result.

Providing another way to use the content

Each activity comes with a static text version.

Learners can use it as a study reference or as another way to access the material. It also provides readable course content for features that may not be able to interpret the interactive component directly.

I included this alongside the interactive output so both versions are part of the designer’s workflow from the start.

What I wanted to make easier

The tool brings choosing a format, previewing an activity, editing its content, and preparing it for Coursera into one workflow.

My aim was to give our team more room to create small learning activities, with opportunities to review the content and consider accessibility along the way.
